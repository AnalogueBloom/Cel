# Cel

## Run the game

Open a terminal in this folder and start a local web server:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000/celeste.html

Keep that terminal open while playing. To stop the server, press `Ctrl+C`.

To restart it later, run the same command again from `/workspaces/Cel`:

```bash
cd /workspaces/Cel
python3 -m http.server 8000
```

In GitHub Codespaces, open the **Ports** panel, forward port `8000`, and use the forwarded URL when accessing the game outside the Codespace.


https://analoguebloom.github.io/Cel/celeste.html
